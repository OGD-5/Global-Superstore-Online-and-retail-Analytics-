# Global Superstore Business Intelligence & Analytics Project

## Project Overview
This project is part of the AnalystLab Africa Data Analytics Internship Programme (Week 2). The objective was to clean, transform, and build an interactive Executive Performance Dashboard for a national retail company analyzing the Global Superstore dataset. 

The analysis identifies global sales trends, product category profitability, and regional market performance to provide actionable strategic recommendations and uncover supply chain risks.

## Tools & Techniques Used
* **Microsoft Power BI:** Interactive Executive Dashboard Development, Data Visualization, Report Connections (Slicers)
* **Power Query:** Data Import, Data Cleaning, Missing Value Handling, Data Type Correction
* **DAX (Data Analysis Expressions):** Custom measure creation for advanced aggregations and Key Performance Indicators (Total Sales, Total Profit, Profit Margin)
* **Business Analytics:** Translating visual data into executive risk assessments and market opportunities

## Key Business Insights
* **Category Profitability:** Technology is the primary driver of both top-line revenue and bottom-line profit, led heavily by high-margin products like Copiers and Phones.
* **Customer Segment Dominance:** The Consumer segment represents over 50% of the total sales and orders, indicating a massive reliance on personal retail spending habits compared to Corporate or Home Office clients.
* **Geographic Concentration:** The APAC (Asia-Pacific) and European (EU) markets dominate global sales volume, outperforming newer or smaller regions like Africa and Canada.
